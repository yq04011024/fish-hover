# 聚焦视界（B站悬停刷视频）

在编辑器侧边栏刷 B 站视频的摸鱼插件：仿 B 站推荐流页面、热门/直播/待看分区浏览、扫码登录、稍后再看、Cookie 个性化推荐、关键词搜索，一键切换「是否伪装」双形态。**0.3.0 起新增独立「抖音视界」**：竖向沉浸式刷抖音推荐与关注视频。

> 本插件仅供学习交流，B 站/抖音相关数据均来自对应平台公开接口，版权归各平台所有。

## 功能特性

| 特性 | 说明 |
| --- | --- |
| 抖音视界（0.3.0 新增） | 活动栏独立入口，竖向沉浸式上下滑动切换视频（同抖音网页版交互），分区：**推荐 / 关注** |
| 抖音本地媒体代理 | 视频流经 `127.0.0.1` 随机端口本地代理转发（附带 Cookie/UA/Referer、透传 Range 支持进度条拖动），解决 webview 直连抖音 CDN 403 |
| 抖音 Cookie 登录态 | 手动粘贴抖音 Cookie（`douyin.com` 抓取），推荐/关注流均需登录态；未配置时页面引导设置 |
| 抖音上下切换 | 滚轮/↑↓ 键/命令（上一个、下一个视频）切换；自动播放、静音降级提示、点击画面恢复声音；接近底部自动加载更多 |
| 双形态一键切换 | 标题栏「切换是否伪装」按钮，切换后视图与面板立即重渲染，无需重启 |
| 仿 B 站页面（不伪装模式，默认） | 毛玻璃顶栏 + bilibili 字标 + 分区标签页，卡片流样式与 B 站一致 |
| 分区浏览 | 推荐 / 热门 / 直播 / 待看 分区真实可用；热门支持「加载更多」翻页，直播支持「加载更多」持续拉取轮换的新直播间 |
| 扫码登录 | 右上角「登录」弹出 B 站扫码二维码，APP 确认后自动保存登录态；登录后悬停头像可「退出登录」 |
| 原位播放 | 点击卡片封面，视频在原封面框内直接播放（右上角 ✕ 恢复封面），自动播放、记忆音量 |
| 直播观看 | 直播分区卡片原位播放 HLS 直播流（基于 hls.js） |
| 稍后再看 | 悬停卡片点击时钟按钮，一键加入 B 站「稍后再看」（需登录） |
| Cookie 个性化推荐 | 扫码登录自动写入 Cookie；也可手动粘贴，未登录时随机推荐 |
| 关键词搜索 | 搜索B站视频并支持结果分页浏览 |
| 随机播放 | 一键从当前列表随机播放（按当前形态自动分流到对应播放方式） |
| 伪装模式 | 侧边栏为普通视频列表；点击后在编辑区打开播放面板，面板伪装成本地代码文件（默认标题 `jsProject00111.js`），画面被遮罩盖住并显示伪装文件内容（编辑器风格带行号），**聚焦/悬停显示画面、失焦自动恢复伪装**（音频持续） |
| 播放配置 | 自动播放、初始音量、面板宽度拖拽记忆（伪装面板） |

## 快速开始

1. 点击活动栏的「聚焦视界」图标打开侧边栏
2. 点击右上角「登录」按钮，用 B 站 APP 扫码登录（可选，登录后推荐按账号个性化加载，并解锁「待看」分区）
3. 点击列表中的视频在封面原位播放；点击标题栏眼睛按钮可随时切换伪装/不伪装

## 标题栏按钮

| 按钮 | 功能 |
| --- | --- |
| 🔍 搜索视频 | 输入关键词搜索B站视频 |
| ▶ 随机播放 | 从当前列表随机播放一个视频 |
| 👁 切换是否伪装 | 在「伪装/不伪装」两种形态间切换 |
| ⚙ 设置B站Cookie | 手动粘贴 Cookie 启用个性化推荐 |
| ↻ 刷新视频 | 重新加载推荐列表 |

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `biliHover.disguiseEnabled` | `false` | 是否伪装。关闭：侧边栏视频流，卡片原位播放；开启：侧边栏视频列表，编辑区面板伪装为代码文件，画面遮罩、聚焦显示/失焦隐藏 |
| `biliHover.userCookie` | 空 | B 站账号 Cookie，扫码登录成功后自动写入；也可手动粘贴（仅保存在本机设置中，只用于请求B站接口） |
| `biliHover.autoStartPlayback` | `true` | 打开播放面板时自动开始播放 |
| `biliHover.initialVolume` | `0.2` | 播放器初始音量（0-1） |
| `biliHover.playerPaneWidth` | `400` | 播放面板宽度（像素），可在面板内拖拽调整并自动记忆 |
| `biliHover.playerPaneTitle` | `jsProject00111.js` | 伪装模式下播放面板的标题文字 |
| `biliHover.disguiseFilePath` | 空 | 伪装面板遮罩显示的本地文本文件绝对路径（留空为纯黑） |
| `biliHover.sidebarViewTitle` | `聚焦视界` | 侧边栏视图标题（修改后需重启生效） |
| `biliHover.douyinCookie` | 空 | 抖音账号 Cookie（浏览器打开 douyin.com → F12 → Network 请求头复制），推荐/关注流均需登录态；仅保存在本机设置中 |
| `biliHover.douyinAutoPlay` | `true` | 抖音视频滑动到可视区后自动播放 |
| `biliHover.douyinVolume` | `0.5` | 抖音播放器初始音量（0-1） |

## 使用建议（伪装模式）

- 将 `biliHover.playerPaneTitle` 改成你项目中常见文件名（如 `utils.js`），将 `biliHover.disguiseFilePath` 指向一个真实的代码文件，伪装效果更自然
- 悬停面板即可看视频，鼠标移开立即恢复伪装内容，降低被打扰的风险

## 隐私与安全

- 扫码登录直接与 B 站官方登录接口通信，登录态（Cookie）写入本机用户设置；退出登录即从设置中清除
- Cookie 仅存储在本机用户设置中，不经过任何第三方服务器，仅随请求发送给 B 站官方接口
- 插件不采集、不上传任何用户数据
